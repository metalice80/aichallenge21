# Руководство локального индексатора

Это расширенный демонстрационный документ для проверки обработки коллекции объёмом в несколько десятков страниц.


## Установка

Установка начинается с Python 3.11 или новее, изолированного виртуального окружения и команды pip install -r requirements.txt. После установки приложение запускают командой streamlit run app.py. Первый запуск загружает многоязычную модель, дальнейшая работа выполняется локально.
